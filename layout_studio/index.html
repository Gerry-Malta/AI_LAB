LAYOUT STUDIO · CONTROLS

RMB draglook around (Unreal style). Hold RMB and use WASD to fly, Q/E down/up, Shift faster, mouse wheel changes fly speed.
wheeldolly forward/back when RMB is not held.
MMB dragpan (track).
Alt+LMBorbit around the focus point.
LMB clickselect object or shot camera. Esc deselects.
W E Rgizmo: move / rotate / scale (when RMB is not held). Del deletes the selection.
Fframe the selection.
Spaceplay / pause the current shot. [ ] previous / next shot.
Llook through the shot camera, letterboxed to the lens aspect, with live subtitles. With ▶ all this is a real-time screening of the edit. While looking through, RMB + WASD drive the shot camera itself and write the active key (A/B) when you release.
G H Mtoggle grid / labels / actor marks (floor rings for every beat).
Stepsthe left panel follows the work: 1 Set, 2 Blocking, 3 Camera, 4 Sound, 5 Review. Rest the cursor on any control for a short explanation.
Ctrl+Zundo. Ctrl+S download the JSON.
Export MP4renders the edit on this computer's GPU and encodes it in the browser (H.264 where available), with burn-in and subtitles.

Stand-ins are posed per beat: with a shot or a beat selected, moving a stand-in edits that beat's blocking. Shots with different start/end beats interpolate the blocking during the move.

Shot check is deterministic: size read from the body keypoints, headroom, lead room, thirds, horizon, depth layers (FG / MG / BG), occlusion, eyeline, rig limits and the 180° line between shots that declare the same axis.
